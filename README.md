# 比較くん｜複数画像比較

商品ごとの画像をまとめてアップして、**1商品＝1行**で横に並べ、行を重ねて見比べるためのツールです。
アップした画像は GitHub のこのリポジトリに保存されるので、ページを開き直しても・別のPCからでも同じ一覧が見られます。

## 使い方

1. ページを開く（初回のみ ⚙ 設定でトークンを入力。同じブラウザで「表示確認くん」に設定済みなら不要）
2. 1商品分の画像をまとめてドラッグ＆ドロップ（ページのどこに落としてもOK）
3. すぐ一覧に1行追加され、裏で GitHub にアップされます
4. 次の商品の画像をドロップ → 下に次の行が追加
5. 画像クリックで拡大。`← →` で同じ商品の前後、`↑ ↓` で他の商品の**同じ番号**の画像に切替

- 画像はファイル名順（1, 2, …, 10 の自然順）に左から並びます
- 商品名は入力欄に入れておくか、空欄ならファイル名から自動で付きます。あとから名前をクリックで変更可
- 「削除」でその商品の行と GitHub 上の画像を削除
- 画像の幅は 小/中/大 と ±ボタンで調整（ブラウザに記憶）

## 保存の仕組み

- 画像：`shared/hikaku/g<時刻>/01.jpg …`（長辺1600px・JPEG品質85%に圧縮）
- 一覧：`shared/hikaku/manifest.json`
- 1回のアップ／名前変更／削除が、それぞれ1コミットになります

## 必要なもの

- **公開リポジトリ**（画像を raw.githubusercontent.com から表示するため）
- GitHub Personal Access Token（このリポジトリに対して Contents: Read and write）

## ファイル構成

- `index.html` … ツール本体（これ1つで完結）
- `shared/hikaku/` … アップした画像と一覧（ツールが自動で作成）
